# For Contribzzzz (instructions)

## Steps

- fork the repo
- clone the forked copy
- create a new branch
- make changes
- push changes to your branch
- open a pull request

## Adding/Running code

**contributing to project (bash)**

```Bash
python -m venv venv
pip intall -r requirements.txt
source venv/bin/activate
```

now you can add all the code!

**to deactivate venv interpreter**

```Bash
deactivate
```

**running the code (as package)**

```Bash
# Example
python -m src.data_preprocessing.loader
```
